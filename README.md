# 電卓（Web版・PWA）

Android版・iOS版と同じ機能をブラウザで動くようにしたものです。
iPhoneでもAndroidでも、同じURLで使えます。

## Netlifyで公開する手順（いちばん簡単な方法）

1. このzipを解凍して `calculator-web` フォルダを用意する
2. https://app.netlify.com/drop を開く（Netlifyにログインしておく）
3. `calculator-web` フォルダを、そのままページにドラッグ＆ドロップする
4. 数秒で `https://○○○.netlify.app` のURLが発行される
5. 「Site configuration」→「Change site name」で、URLを好きな名前に変更できる

更新するときは、サイトの「Deploys」タブを開き、修正したフォルダを再度ドラッグ＆ドロップします。

## スマホのホーム画面に追加する

- **iPhone（Safari）**：URLを開く →「共有」ボタン →「ホーム画面に追加」
- **Android（Chrome）**：URLを開く → 右上の「︙」→「ホーム画面に追加」（または「アプリをインストール」）

ホーム画面のアイコンから開くと、アプリのように全画面で表示されます。一度開けば、電波がない場所でも使えます。

## 機能

| 機能 | 使い方 |
|---|---|
| 四則演算・連続計算 | `123 + 456 -` → 579 のように、前の計算を先に実行して続ける |
| 3桁カンマ区切り | 自動 |
| ⌫（バックスペース） | 入力中の数字を1桁消す。計算結果に押すと結果を編集できる |
| = の長押し | 同じ計算を繰り返す |
| OFF% / UP% | 金額 → `OFF%` → 率（例 10）→ `=` |
| 税込 | 表示中の金額に8%を加算 |
| 表示欄をタップ | 数値をコピー |
| 履歴 | 計算の履歴を新しい順に表示（アプリを閉じると消える） |
| 商品登録 | 種類 → 用途 → メーカー → 商品名・金額。登録済み商品の削除もここから |
| 商品呼び出し | 両目の度数が同じ／違う、同じ商品で揃える／違う商品にする、に応じて金額を自動入力 |

## 注意

- 商品データは**その端末のブラウザの中**に保存されます。別の端末とは共有されません。
- ブラウザの「履歴とWebサイトデータを消去」をすると、登録した商品も消えます。
- iPhoneでは、Safariで開いた場合とホーム画面から開いた場合で、保存場所が別になります。普段使う方で登録してください。
- プライベートブラウズでは商品が保存されません。
- 税率を変えたいときは `calc.js` の `TAX_RATE = '8'` を書き換えます。

## ファイル構成

```
calculator-web/
├── index.html            画面
├── style.css             見た目
├── calc.js               計算ロジック
├── app.js                ボタン操作・商品登録・呼び出し
├── manifest.webmanifest  ホーム画面追加用の設定
├── sw.js                 オフライン対応
├── netlify.toml          Netlify用の設定
└── icons/                アプリアイコン
```
